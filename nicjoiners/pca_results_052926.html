PC1: Parental Education / First-Gen
2 variables · loadings 0.89-0.90
Highest parental education-0.90
First-gen status-0.89
Near-perfect redundancy. These two variables are measuring the same thing. Use one.

Students whose parents did not attend college are systematically less likely to join a fraternity, and this component captures that in a single clean signal. Because parental education and first-generation status load almost identically (0.90 and 0.89), only one variable is needed in any subsequent model.

All 11 concern items move together as one underlying attitude rather than as 11 separate concerns. Addressing any one concern in isolation is unlikely to move the needle; the barrier is a holistic skepticism toward fraternity culture.

Individual sport indicators add little on top of the count, so collecting sport-specific data provides minimal additional value for predicting membership interest.
